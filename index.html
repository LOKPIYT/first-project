Mobile Phone Automation Guide (Android & iOS)
Mobile Friendly

If you want to automate sending "." directly on your smartphone without a computer, choose your operating system below:

🌐 Method 1: Mobile Browser Bookmarklet (Easiest)

You can run Snapchat Web directly on your phone's browser!

  1. On your phone, open Chrome, Safari, or Kiwi Browser.
  2. Go to web.snapchat.com and enable "Desktop Site" in browser settings.
  3. Log in to your Snapchat account.
  4. Paste the SnapDot bookmarklet code into the address bar or run via developer tools.
  5. The SnapDot floating panel appears, letting you tap "Start Auto-Sending"!

🤖 Method 2: Android Auto Clicker (Native App)

Use an accessibility-based tap recorder for the official Snapchat mobile app:

  1. Download Auto Clicker - Automatic tap from Google Play Store (free).
  2. Grant Accessibility permission.
  3. Set up a multi-target sequence:
    • Tap 1: First friend in chat list.
    • Tap 2: Chat input box.
    • Tap 3: Period key "." on keyboard.
    • Tap 4: Send arrow button.
    • Tap 5: Back button.
  4. Repeat for target 2, 3, etc. Save this macro and press Play anytime!

🍎 Method 3: iPhone / iOS Shortcuts

Automate opening chats on iOS:

  1. Open the Shortcuts app on iOS.
  2. Create a new shortcut with the "Open URL" action.
  3. Use Snapchat URL schemes: snapchat://chat/[username] to open directly to each chosen friend.
  4. Use the Text action with "." and Copy to Clipboard, so you only tap Paste and Send!
